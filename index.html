Perangkat Pendukung Koding & AI

Sebelum kita membuat program komputer atau aplikasi AI, kita memerlukan dua jenis perangkat utama: **Perangkat Keras (Hardware)** dan **Perangkat Lunak (Software)**.

2. Perangkat Input AI (Kamera & Mikrofon)

Bagaimana sensor, kamera, dan mikrofon membantu AI mengenali dunia.

A. Perangkat Keras (Hardware) Utam Koding

Koding membutuhkan alat pemrosesan instruksi. Berikut perangkat keras pendukung utamanya:

Komputer / Laptop / Tablet

Perangkat tempat menulis program, menjalankan perintah koding, dan mengolah data.

Keyboard & Mouse

Perangkat masukan (input) untuk mengetik baris kode perintah dan mengarahkan kursor.

Microcontroller (Micro:bit / Arduino)

Papan sirkuit kecil yang diprogram untuk mengendalikan lampu LED, motor, dan robotik.

Processor & RAM

Otak utama komputer yang memproses perhitungan logika program secara cepat.

B. Perangkat Pendukung Kecerdasan Artifisial (AI)

AI membutuhkan indera buatan untuk "melihat", "mendengar", dan "memahami" lingkungan sekitar:

Kamera / Webcam (AI Visual Vision)

Digunakan AI untuk mengenali wajah manusia, objek gambar, gestur tangan, atau mendeteksi warna.

Mikrofon (Speech & Voice Recognition)

Merekam suara manusia agar sistem AI seperti Google Assistant atau Siri dapat menerjemahkan perintah ucapan.

Jaringan Internet / WiFi Router

Menghubungkan komputer lokal ke Server Cloud tempat model AI besar (seperti ChatGPT atau Google Gemini) berjalan.

Kartu Grafis GPU (Graphics Processing Unit)

Komponen khusus yang mempercepat pemrosesan data matematika ribuan gambar & suara pada model AI.

Perangkat Lunak (Software)

  • Scratch / Blockly: Software koding berbasis blok warna-warni ramah anak.
  • Teachable Machine: Platform web AI dari Google untuk melatih kamera/mikrofon.
  • Web Browser (Chrome/Edge): Perangkat lunak untuk mengakses platform koding online.
